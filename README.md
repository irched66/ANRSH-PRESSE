# ANRSH PRESSE

المجلة الإلكترونية للجمعية الوطنية لمتقاعدي سوناطراك.

## محتويات المشروع
- `index.html`: الواجهة الرئيسية، متجاوبة مع الهاتف وتدعم العربية والفرنسية والإنجليزية.
- `manifest.webmanifest`: بيانات تثبيت المجلة كتطبيق ويب.
- `sw.js`: التخزين المؤقت والعمل عند ضعف الاتصال، مع تحديث نسخة الواجهة.
- `icon.svg`: أيقونة مؤقتة تحمل كتابة ANRSH PRESSE.
- قسم خدمات الصندوق الوطني للتقاعد CNR مع رابط صفحة CNR على فيسبوك.
- روابط الصفحة الرسمية للجمعية والبريد الإلكتروني.

## النشر عبر GitHub Pages
1. افتح إعدادات المستودع **Settings**.
2. اختر **Pages**.
3. في **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع **main** والمجلد **/(root)** ثم اضغط **Save**.
5. انتظر اكتمال النشر، ثم افتح رابط Pages.

## إضافات واجهة القراءة المضافة
- شريط تاريخ وساعة مباشرَين بتوقيت الجزائر، مع ترحيب بالعربية والفرنسية والإنجليزية.
- عداد محلي يوضح عدد الزيارات المسجلة على المتصفح الحالي فقط؛ لا يمثل إجمالي زوار الموقع.
- بحث داخل محتوى الأقسام الظاهرة.
- وضع ليلي، تكبير وتصغير الخط، وقراءة صوتية للنص عند دعم المتصفح.
- أبواب «ذاكرة سوناطراك» و«صوت المتقاعد» ومكتبة المجلة وأرشيف الأعداد.
- قسم العدد الافتتاحي رقم 01 — ديسمبر 2026، مع توضيح أن ملف PDF سيضاف بعد اعتماد النسخة النهائية.

## ما يحتاج ربطاً خلفياً قبل اعتباره خدمة مكتملة
- عداد إجمالي الزوار وزوار اليوم على مستوى جميع الأجهزة يحتاج قاعدة بيانات وواجهة API؛ العداد الحالي محلي فقط.
- استقبال الرسائل والتعليقات وحفظ البريد بسرية ومراجعتها قبل النشر يحتاج خدمة خلفية آمنة. رابط البريد الحالي يفتح تطبيق البريد ولا يحفظ الرسائل داخل المجلة.
- رفع ألبومات الصور وتنزيلها، ونشر المقالات وإدارة الأخبار العاجلة، وأرشفة ملفات PDF تحتاج تخزيناً وقاعدة بيانات وصلاحيات خادمية.
- خريطة المكاتب ودليل الاتصال يحتاجان بيانات رسمية معتمدة قبل عرضها.

## حالة الوظائف — بشفافية
هذه النسخة واجهة مجلة إلكترونية قابلة للتصفح، وليست بعد نظام تحرير ونشر متكاملاً.
- فضاء رئيس التحرير ظاهر كواجهة تعريفية فقط؛ المصادقة الآمنة غير مفعّلة.
- لا توجد قاعدة بيانات مرتبطة لحفظ المقالات أو الصور بين الأجهزة.
- لا توجد لوحة إدارة فعلية لإضافة الأخبار أو مراجعتها أو اعتمادها أو حذفها.
- صورة رئيس المكتب الوطني والغلاف الرسمي الأصلي لم يدرجا بعد؛ الأيقونة الحالية مؤقتة ولا تمثل الشعار الأصلي.
- رابط CNR ورابط صفحة الجمعية يفتحان صفحات خارجية، ولا يعني ذلك وجود تكامل آلي معها.

**تنبيه أمني:** لا تضع كلمات مرور أو مفاتيح API أو بيانات شخصية في ملفات HTML أو JavaScript العامة.

## ما يلزم قبل إعلان المجلة جاهزة
1. توفير الصورة الأصلية المعتمدة للغلاف والشعار وصورة رئيس المكتب الوطني.
2. إنشاء قاعدة بيانات وربطها بخدمة خلفية مستضافة.
3. تفعيل تسجيل دخول آمن للمحررين مع صلاحيات واضحة.
4. بناء إدارة المقالات والصور، وحالات المسودة والمراجعة والاعتماد والنشر.
5. اختبار النشر على الهاتف والحاسوب، واختبار الصلاحيات والنسخ الاحتياطي.
