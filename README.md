# ANRSH PRESSE

المجلة الإلكترونية للجمعية الوطنية لمتقاعدي سوناطراك.

## الملفات
- `index.html`: الصفحة الرئيسية للمجلة، متجاوبة مع الهواتف، وتدعم العربية والفرنسية والإنجليزية.
- الموقع مستقل تماماً عن منصة الانخراط والبطاقات الرقمية ANRSH DIGITAL.

## تشغيل الموقع عبر GitHub Pages
1. افتح إعدادات المستودع **Settings**.
2. اختر **Pages**.
3. في **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع **main** والمجلد **/(root)** ثم اضغط **Save**.
5. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## ملاحظات تحريرية مهمة
- لا توجد مقالات أو أخبار جاهزة للنشر في النسخة الأولى؛ لن نضع أخباراً غير متحقق منها.
- قبل نشر أي خبر يجب التحقق من المصدر والجهة والتاريخ والرابط الأصلي.
- واجهة رئيس التحرير والنشر الآمن وربط قاعدة البيانات لم تُنفذ بعد. لا تضع كلمات مرور أو بيانات شخصية في ملفات الموقع العامة.
- لا يحتوي هذا الإصدار على اتصال بـ Meta API أو نشر تلقائي على Facebook.


## المرحلة الأولى — الغلاف الأسبوعي
- أضيف موضع الغلاف الافتتاحي للعدد الأول في الصفحة الرئيسية.
- مسار صورة الغلاف المعتمدة: `assets/cover-nov-2026.jpg`.
- يجب إضافة ملف الصورة الأصلي إلى هذا المسار قبل دمج التغيير أو نشره؛ لم يُنشر هذا الفرع ولم يتغير موقع الإنتاج.
- ابتداءً من العدد التالي، يستبدل فريق التحرير ملف الغلاف الأسبوعي مع الاحتفاظ بأرشيف الأغلفة السابقة.
- لا تزال لوحة التحرير الآمنة وربط D1 خارج نطاق هذه الواجهة، ولا يجوز اعتبارها منفذة.
